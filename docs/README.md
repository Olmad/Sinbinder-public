# Документация Sinbinder

## Правило этой папки

Каждое утверждение здесь сверено с кодом. Где система описана, но не работает —
это написано прямо, со ссылкой на файл и строку.

Причина строгая: у проекта уже была документация, описывавшая системы, которых
не существовало. Диздок, которому нельзя верить, хуже отсутствия диздока —
он создаёт ощущение сделанной работы там, где её нет.

Формат пометок:

| Метка | Значение |
|---|---|
| **РАБОТАЕТ** | код есть, подключён, исполняется |
| **НАПИСАНО, НЕ ПОДКЛЮЧЕНО** | класс есть, но его никто не вызывает |
| **СПРОЕКТИРОВАНО** | есть в замысле, кода нет |
| **ПРЕДЛОЖЕНИЕ** | придумано в ходе анализа, автором не утверждено |

## Версия

Диздок v5.0, август 2026. Сведён из GDD v4.4, AOS Volume 0/I/II и переписки,
плюс аудит 124 файлов исходников.

Главное отличие от v4.4: зафиксировано решение о подчинении как исходе
голосования, а не как обходе AOS. Убраны обещания, не подтверждённые кодом.
