# Как показывать демо

Проверено 24 сентября: слияние с облачной сессией (61 коммит),
компиляция, самопроверка движка **336 из 336**, прохождение демо
**целиком — 28 шагов**, пересборка игры и запуск собранной.

## Чем запускать

**Готовая игра:** `Build\Sinbinder\Sinbinder.exe` — 130 МБ, пересобрана
24 сентября со всеми правками. Собирается заново пунктом меню
**Sinbinder → Собрать игру**; в репозиторий не кладётся — пересобрать
дешевле, чем хранить.

Проверена запуском: навмеш печётся, лагерь собирается, десять воинов
создаются, **ни одного исключения**. Показывать можно с неё — тогда
зритель не видит редактора.

Из редактора показывать тоже можно: сцена `Assets/Scenes/Prologue_Camp`.

## Что нажимать

| Клавиша | Что делает |
|---|---|
| **W A S D** | ведёт камеру; в виде от первого лица — идёт сам Греховод |
| **V** | переключает вид: сверху ↔ от первого лица |
| **край экрана мышью** | ведёт камеру (работает, только когда курсор в окне) |
| **ЛКМ, рамка** | выделить воина или отряд; **Shift** — добавить к выделенным |
| **ПКМ по земле** | приказ идти; **Shift + ПКМ** — «отходи», а не «иди туда» |
| **ПКМ по врагу** | «бить» — только живого и видимого |
| **H** | держать строй |
| **G** | оборона |
| **1…6** | установка отряду: без указаний, в атаку, прикрывать своих, беречь себя, собирать добро, держаться приказа |
| **F** | заговорить, сесть за стол, взяться за предмет |
| **E** | забрать душу павшего |
| **R** | переложить: из руки в ячейку сумы и обратно |
| **Tab** | следующая ячейка сумы |
| **I** | вещи выделенного: обмен, если он рядом |
| **O** | окно прозрачности: почему воин поступил так |
| **Esc** | пауза, закрыть окно |
| **F5 / F6** | быстро сохранить / загрузить |

## Порядок показа

Ровно то, что проходит автопрогон, — **двадцать восемь шагов**, целиком,
без единого сбоя (24 сентября).

1. **Вопрос о сохранении.** «Начать заново». Чёрный экран, одна строка:
   *«Греху всё равно, чьё это тело»*. Три секунды — и лагерь.
2. **Лагерь.** Девять воинов у костра, палатки, частокол. Пять палаток
   брошены, у каждой колышек с именем павшего — это вся предыстория,
   которую стоит назвать вслух.
3. **К столу, F — военный совет.** *Здесь главное решение демо.* Слева
   имена, у каждого сказано, сколько он уведёт и почему не годится.
   Назначьте старшего — и отряд уйдёт. Вернётся не весь и не таким.
4. **Сундук, тревога.** Охотники узнали, где лагерь.
5. **Набег.** Инквизиторы и охотники — люди, не чудовища. Бой,
   **E** — забрать душу. Вложить её в тело в прологе негде: связывание
   живёт в мастерской склепа, а её пролог не показывает.
6. **Отход к краю.** Полосы сверху и снизу, реплика на нижней.
7. **Склеп.** Плата, эпилог: кто вернулся, кого ждать перестали.

## О чём сказать самому, пока не спросили

- **Приказ — это голос, а не команда.** Воин голосует внутри себя,
  и приказ игрока участвует наравне с его грехом, моралью и памятью.
  Отказ — не поломка, это и есть игра. «Не командуй. Искушай».
- **Цифр игрок не видит никогда** — ни очков, ни процентов, только
  слова. Это правило проверяется автоматически.
- **Ничего случайного.** Одинаковый вход даёт одинаковый выход,
  и одно решение всегда объясняется одними и теми же словами.

## Чего в демо нет — говорить прямо

- **Звука почти нет.** Ни одного файла; звучат только голоса реплик,
  их синтезирует код. Рог отхода молчит — пишет строку в журнал.
- **Мастерская склепа** (полка душ, стол тел, устройство связывания)
  осталась примитивами: пролог её не показывает.
- **Бой один** — набег. Полигон с рычагами есть отдельной сценой,
  в демо он не участвует.
- **Модели собраны кодом**, нарочно простые. Пропорции сверены
  с образцами; облик держится силуэтом и цветом греха, а не деталями.
- **У тумана войны рваный край.** Видимость работает верно, но граница
  затемнения идёт прямоугольником с зубцами. Косметика, замечена
  24 сентября; не трогали, чтобы не ломать перед показом.
