# Tools

## check.py — статическая проверка исходников

```
python3 Tools/check.py          # список замечаний
python3 Tools/check.py --quiet  # только итог
```

Не заменяет компилятор. Ловит тот класс ошибок, из-за которых Unity
не собирает проект **вообще** — а значит, не показывает и остальные:

| Что | Пример из этого проекта |
|---|---|
| CS0246: тип из чужого namespace без `using` | `SinType` в `InventoryItem`, `Warrior` в `VoiceGenerator` — 11 файлов |
| CS0246: тип не объявлен нигде | шестнадцать типов, на которые ссылался код |
| CS0101: тип объявлен дважды | два `GreedModule` в одном пространстве имён |
| CS1503: литерал не того типа | `CreateMemory(…, "гнев", …)` вместо `EmotionType` — семь вызовов |
| CS0841: переменная использована выше объявления | десять строк в `CombatDecisionContext` |
| CS1061: LINQ без `using System.Linq` | там же |
| Скобки не сходятся | — |
| Имя файла ≠ имя MonoBehaviour | `GluttonySkills .cs`, `Inventory.cs`, `TitleCeremony.cs` |
| `using UnityEditor` без `#if UNITY_EDITOR` | три редакторных скрипта; ломает сборку плеера |
| Обёртка стоит ниже `using UnityEditor` | `IconGenerator` — обёртка не работала |

Всего этой проверкой в проекте найдено **двадцать три** ошибки
компиляции, каждая из которых в одиночку не давала собрать проект.

Проверка сама проверена: девять ошибок каждого вида подсаживались
в копию исходников намеренно, все девять найдены.

Чистый результат означает отсутствие ошибок **известных видов** —
не гарантию сборки. Перегрузки, версии API Unity и `.meta`-файлы
проверяются только редактором.

## Что проверяет сам движок

`Tests/SelfCheck.cs` — проверка логики, а не синтаксиса:
спектры, перенос старых душ, распад, оболочки, искушения, геометрия
удара в спину, правила голосования и правило «игрок не видит цифр».

Запуск: меню **Sinbinder → Проверить движок** (Ctrl+Shift+T),
либо компонент `SelfCheckRunner` на объекте сцены.
