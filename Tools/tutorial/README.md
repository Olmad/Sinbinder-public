# Автоматические проверки обучения Sinbinder

Тестовый контур, связанный с **реальными правилами** в
`Assets/Scripts/Gameplay/DreamTutorialChecks.cs`. Не отдельная копия загадок.

## Запуск локально

Для .NET SDK 8:

```bash
dotnet run -c Release --project Tools/tutorial/TutorialChecks.csproj
```

Для полной синтаксической проверки нужен **SDK 8**, закреплённый локальным
`Tools/tutorial/global.json`. Находясь в `Tools/tutorial`, выполнить:

```bash
dotnet run -c Release --project SyntaxChecks.csproj -- ../../Assets/Scripts
```

GitHub Actions: [Dream tutorial logic smoke](../../.github/workflows/tutorial-smoke.yml).
На push в `feature/server-prototype` и на подходящий PR проверяются оба теста.

## Что действительно проверяется

1. Геометрия знаков склепа (радиус 1,35 м): воин на далёкой плите не считается.
2. Противовес: обе плиты до падения груза заблокированы.
3. Непрерывное удержание двух плит 1,2 с и сброс после ухода одной фигуры.
4. Доказательство АОS: должен быть **новый контекст голосования**
   после правильного приказа, а не ранее записанный вердикт.
5. Спасение: только реальный `Bodyguard.Absorb` обращается к
   `RescueCreditGate`; награда не спамится за каждое повторение.
6. Roslyn читает синтаксис **всех** C#-файлов проекта с двумя наборами
   символов препроцессора (Unity Player и `UNITY_EDITOR`).
   Это проверка грамматики, а не всех ссылок на Unity-типы.

## Чего эти проверки НЕ доказывают

- Открытие сцен в Unity 6000.3.22f1, компиляцию всех компонентов с реальным
  `UnityEngine` и настоящим `UnityEditor`.
- Наличие нужных объектов сцены, работающий NavMesh, визуальную читаемость
  кругов/весов, анимации, реальную кликабельность и звук.
- Реальное голосование всех 13 модулей AOS в контексте полной сцены.
  Проверяется правило достоверности результата; для самой сцены нужен
  `DreamWalkthrough` или человек в Unity.
- Доступность завершения урока при **любом** исходе души.
- Прохождение игроком без подсказок. Автопрогон из Editor использует
  явно помеченные обходы для отдельных операций.

## Полное принятие обучения

1. Компиляция в Unity и отсутствие `MissingScript`.
2. Ручной путь: суд, виды Tab/V, лук, противовес, реальное SaveAlly,
   два характера, страх, две плиты, пробуждение.
3. Прогон `Sinbinder.EditorTools.DreamWalkthrough.Run` в Unity и
   анализ `Logs/dream-walkthrough.txt` с выделением обходов.
4. Отдельная проверка отказов AOS, гибели, повторов и восстановления.
5. Минимум трое игроков, не читавших код или GDD.
