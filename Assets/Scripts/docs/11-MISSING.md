# Чего не хватает

## Реестр · обновлён 28 августа

Реестр создавался как список недостающего кода. За один заход список
кода закрыт целиком. Осталось то, что кодом не делается.

**Важная оговорка.** «Написано» не значит «работает». Ни одна строка
ниже не проверена компилятором: в этой среде нет ни Unity, ни `csc`.
Проверка была статической — разбор объявлений и вызовов по 145 файлам.
До первого запуска в редакторе всё в первой таблице считается
написанным, а не сделанным.

## 2. Осталось: не код

Это и есть весь остаток. Ни одну строку здесь нельзя написать
из текстового редактора.

### 2.1 Запустить

Первое и единственное, что имеет значение сегодня. Пока не нажат Play,
всё выше — гипотеза.

Ожидать надо не «ноль ошибок», а список: перегрузки, версии API,
`.meta`-файлы. Это нормальный исход, а не провал.

### 2.2 Ассеты

| Что | Кто требует | Без него |
|---|---|---|
| `Resources/AOSConfig.asset` | все модули | работает на значениях по умолчанию, но балансировать нечем |
| `Resources/Icons/Attack`, `SaveAlly`, `Loot`, `Flee` | `AOSWarriorWrapper` | первая ступень прозрачности молчит |
| `Resources/PerkDatabase.asset` | `PerkResolver` | сто перков не подключить |
| `DialogueDatabase.asset` | `DialogueLoader` | реплики вырождаются в `[Имя]: ...` |
| `ShellData` ×4–6 | сборка воинов | оболочки не из чего выбирать |
| `CrisisDatabase.asset` | `CrisisManager` | кризисов нет (вне демо) |

Смещения спектров у оболочек — контент, а не код. Скелет: +Уныние,
−Похоть. Волк: +Гнев, −Терпение. Голем: +Гордыня, −Зависть.

Искушения у предметов (`TemptationSin`, `TemptationValue`) — тоже
контент. Золочёный клинок: Жадность. Верёвка монаха: минус Гордыня.
Фляга: Чревоугодие.

### 2.3 Сцена

Компоненты написаны, но их надо повесить и связать в инспекторе.

**На воина:** `Fatigue`, `Engagement`, `RefusalPresenter`.
**На Canvas:** `BattleLogUI` (Text + CanvasGroup), `WarriorTooltipUI`
(панель, Text, Image рамки), `SoulAssemblyUI` (четыре Text).
**Проверить:** `AOSEventHub` живёт в сцене — без него отказ не поднимет
ни журнал, ни микропаузу.

### 2.4 Баланс

Тринадцать голосов на семи шкалах, и ни одного тестировщика.
Здесь ИИ бесполезен: сказать «отказ случается слишком часто» может
только человек, которому не весело.

Первое, что почти наверняка придётся крутить: `HesitationGap`.
Порог 10 задавался при шести кандидатах; теперь их до пятнадцати,
и колебание станет чаще. Скорее всего порог придётся поднимать.

### 2.5 Арт, звук, витрина

Без изменений: `08-FLOOR.md`, `09-PROLOGUE.md`, `06-SELLING.md`.

## 3. Что делать в первый вечер

1. Открыть проект, нажать Play, записать список ошибок целиком.
2. Починить его.
3. Создать `Resources/AOSConfig.asset` — иначе баланс не крутится.
4. Повесить `Fatigue` и `Engagement` на одного воина, `BattleLogUI`
   на Canvas.
5. Отдать приказ отойти воину, сцепленному в ближнем бою, жадному
   и не получавшему платы три вылазки.

Если он откажется и в углу появится строка «Марга не выполнил приказ:
ему не платили третью вылазку подряд» — игра существует.

Это и есть та самая гифка.
