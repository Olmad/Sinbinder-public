# 47. Проход по текстам: было → стало

Автор, 16 октября, о строке совета: «совсем не понятно. Впрочем это
актуально к большинству текстов в игре». Облако: чинить по одной фразе
бессмысленно — нужен проход по всем, экран за экраном, по пути демо.
Автор: «да».

**Как работает.** На экран — таблица. Автор одобряет пачкой: «да» — или
«да, кроме 3 и 7». Только после этого строки правятся
(`46-UI.md` §0: смысл строк не меняется без списка или слова автора).
Правленое помечается **исправлено** с датой.

**Правило для каждой строки** — `37-DEMO.md` §0, п. 2, разложенное на части:

1. **Кто** — назван: не «их», а «охраны»; не «принял», а «повёл к заставе».
2. **Что** — сказано, что случится, а не намёком: «вернётся только в конце».
3. **Сколько** — названо, если от этого зависит решение. Люди считаются
   словами («пятеро», «трое») — это не числа души; монеты — числом
   (решение автора 30 сентября).
4. **Полным предложением**, понятным тому, кто видит игру впервые.
5. **Без загадок** — кроме слухов: в слухе загадка и есть смысл, но тогда
   факты стоят строкой ниже.

**Порядок экранов:** совет (§1), карта вылазок (§2) → разговор → сума →
плата → склеп → эпилог; затем причины отказов в журнале — их больше всего;
затем подсказки.
