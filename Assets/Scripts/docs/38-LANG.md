# 38 — Перевод на другие языки

Автор, 28 сентября: «нам нужно сделать возможность перевода на другие
языки. И если уж совсем нечем заняться, то можешь и перевести игру
на английский».

---

## 1. Как устроено

**Ключ перевода — сама русская строка** (как в gettext). В коде остаётся
живой русский текст — тот, который писали и правили месяцами; перевод
лежит рядом таблицей. Символьные ключи («refusal.distance.pride») развели
бы текст и код: правящий фразу правил бы одно, а игрок читал другое.

| Что | Где |
|---|---|
| Перевод строки | `Core/Loc.cs` — чистый C#, стенд грузит его сам |
| Выбор языка, загрузка таблицы | `Core/LocSetup.cs` — `PlayerPrefs`, `Resources` |
| Таблица | `Assets/Resources/Lang/<код>.txt` — подмножество PO |
| Строка «Язык» | меню паузы (Esc), по кругу; название — на самом языке |
| Язык по умолчанию | русский, пока английский не полон (`LocSetup.EnglishByDefault`) |

Нет перевода — игра показывает русскую строку. Недопереведённая игра
остаётся игрой, а не рассыпается пустыми местами.

## 2. Четыре вызова

```csharp
Loc.T("Пауза")                                  // готовая строка
Loc.F("{0} не выполнил приказ", name)           // строка с местами
Loc.N("медленно")                               // пометка: строка остаётся русской
Loc.Name(warrior.DisplayName)                   // имя при показе
```

## 3. Правила для тех, кто пишет текст

Файл, переведённый на Loc, помечен строкой **`// Перевод: текст через Loc`**.
В таком файле `check.py` (правило `untranslated`) не пропустит русскую
строку мимо Loc. Файлы без пометки — как прежде; их переводит облачная
сессия.

1. **Одна фраза — одна строка с местами.** Не `$"{a} тянет его, " +
   "но не настолько"`, а `Loc.F("{0} тянет его, но не настолько…", a)`:
   переводчику нужен весь смысл, а в другом языке порядок слов другой.
   Места — номерами: `{0}`, `{1}`. Сборщик сверяет, что в переводе те же
   номера.
2. **Статическая таблица — `Loc.N`, перевод — при показе.** Поле
   `static`/`const` собирается один раз, и `Loc.T` в нём перевёл бы
   строку на язык запуска навсегда — смена языка в меню её не тронет.
   `check.py` ловит и это.
3. **Имя — данные.** Души, вещи, титулы в записи и в логике остаются
   русскими (`StartsWith("Ловчий")` в гардеробе работает как работал).
   Переводится только показ: `Loc.Name(…)`. Имена попадают в таблицу,
   если их место в коде помечено `Loc.N("Карган Старый Ворон")`.
4. **Род — парами, как и прежде.** `Grammar.Pick(g, Loc.T("пошёл…"),
   Loc.T("пошла…"))`: переводятся обе формы. Местоимения меняет
   `Grammar.For` — **после** перевода, местоимениями того языка
   (он→она; he→she, him→her, his→her).
5. **Падеж — только русский.** `Grammar.Dative` в другом языке отдаёт
   имя как есть.
6. **В английском настоящем времени — без «his».** Фраза вроде «бьёт со
   всей силы» идёт без пола воина (русский в настоящем времени его
   не несёт), и «strikes with all his might» у женщины соврёт. Пишется
   без притяжательного: «strikes with full force».
7. **Чисел нет** — правило то же на любом языке.
8. **Ключ — не текст.** Строка, которая идёт в память, в сравнение или
   в имя события («ГрабёжБезКрови»), не переводится: помечается
   комментарием `// ключ` на той же строке — `check.py` и `wrap.py` её
   пропускают. Поле с именем на `…Name`, `…Key`, `…Id`, `…Tag`, `…Path`
   и аргумент, чей параметр объявлен как `name`, распознаются сами.

## 4. Инструменты

```
python3 Tools/lang/wrap.py <файл.cs>            показать, что будет обёрнуто
python3 Tools/lang/wrap.py <файл.cs> --write    обернуть
python3 Tools/lang/catalog.py                   обновить таблицу, покрытие по файлам
python3 Tools/lang/catalog.py --todo [часть пути] непереведённое — JSON
python3 Tools/lang/catalog.py --apply перевод.json  влить перевод (места сверяются)
```

`wrap.py` не трогает логику и служебное: сравнения, `case`, `Debug.Log`,
атрибуты редактора, имена объектов, ключи `PlayerPrefs`. Статическую
таблицу он оборачивает в `Loc.N` и напоминает перевести при показе.
После него — прочесть разницу глазами: склейки из кусков сводятся в одну
фразу руками.

**Проверки:**

* `check.py`, правило `untranslated` — русский текст мимо Loc в помеченном
  файле; `Loc.T` в статической таблице. Две ловушки в `check_self.py`.
* Стенд, раздел АНГЛИЙСКИЙ — генератор фраз на английском: подсказка,
  журнал, причина по 60 000 решений без единой русской буквы.
* Самопроверка, раздел `Translation` — таблица читается, места
  подставляются, нет перевода — русская строка, местоимения и падеж —
  языка показа.

## 5. Новый язык

Файл `Assets/Resources/Lang/<код>.txt` (`catalog.py --lang <код>` соберёт
его пустым) и строка в `LocSetup.Languages`. Кода больше не нужно.
Шрифт: нынешний держит кириллицу и латиницу; для иероглифов понадобится
другой.

## 6. Что переведено

Покрытие печатает `catalog.py`. Порядок — от того, что игрок читает
чаще: объяснения отказа → интерфейс (панель приказов, снаряжение, совет,
журнал) → реплики (лагерь, встречи, разговоры) → пролог → титулы
и перки → имена.

**Ещё не решено:** текст, который сборщик сцен (`DemoSceneBuilder`)
записывает в сцену при сборке, — он лежит в сцене готовой строкой
и мимо Loc. Способ — компонент, переводящий свою надпись при появлении
и при смене языка; сделать, когда дойдёт очередь.
