# 56. Передача первому облачному (D, 28.10 → 29.10)

## Почему не через git

Аккаунт Olmad на GitHub заблокирован (403, автор подал запрос на восстановление). D не может пушить:
origin стоит на `9bc7d38`, локальная ветка `claude/3d-horror-survival-game-ckrslc` ушла вперёд на 40+
коммитов. Пока доступа нет — код ходит патчами.

## Как наложить

Автор передаёт `sinbinder-code-since-9bc7d38.zip` — серия `git format-patch` от `9bc7d38` до головы D,
**только код и тексты**: `Assets/Scripts` (без .fbx), `Tools`, `Maps`, `Docs/*.md`.

```
git checkout claude/3d-horror-survival-game-ckrslc
git reset --hard 9bc7d38            # если ветка уже ушла — сначала спросить автора
mkdir /tmp/p && cd /tmp/p && unzip <zip>
cd <repo> && git am --3way /tmp/p/*.patch
```

**Бинарных файлов в патчах нет** (тела `Resources/Bodies/*.fbx` с клипом Gather, звук балалайки,
ворон `Props/Raven.fbx`, префабы `MapProps`, гифки учебника): их делает D у себя Блендером и Unity. Не
пересоздавать — у D они уже есть. Ссылки на них в коде — нормальны, Unity облаку не нужна.

## Как вернуть

Как второй облачный: `git format-patch <голова D>..HEAD` → zip → автору; D накладывает
`git mailsplit` + `git am --3way`. Голову D смотри по последнему патчу серии (строка `From <хэш>`).
