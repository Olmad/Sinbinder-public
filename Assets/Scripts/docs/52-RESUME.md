## Правила, которые нельзя забыть

Женщины — только уникальные и только в основной игре (в демо все мужчины, Марга —
парень). Никакого Random в решениях. Числа: монеты — числом, душа — словами. Звуки —
только CC0. Все мелодии сохранять; музыку автор слушает до установки в игру. Имена
файлов без `: ? * " < > |`. Шипастая пешка — мета-символ: не объяснять, игрок поймёт
сам. Строки не менять по смыслу без таблицы или слова автора (46-UI §0). «Одна новая
вещь за раз» (37-DEMO §0). Решение автора — строкой в `50-CODEX.md` тем же коммитом.
