# 53. Приметы — библиотека, а не девять людей · 28 октября

Автор, 27.10: «Ты понимаешь, что в основной игре должно около сотни генерироваться
с таким же качеством проработки и логики?»

До этого листа примета была человеком: таблица по именам (`Signature`), привычка —
класс на одного (`DiggerHabit` — Марга, `CandleHabit` — Вейн), отклик у костра —
девять строк по именам (`CampfireStoke`), счёт кошеля — тот, кого зовут «Лиска»
(`PurseCounter`). Для демо годится: девять — витрина. Для основной игры — нет:
десятый воин молчит, и в отряде из сотни живы девять.

**Правило:** примета — **запись в библиотеке**. Человек получает её по душе.
В коде ни одной строки с именем человека — кроме тех, кого автор пишет поимённо
(женщины — кодекс §7; легенды; девять демо — как образцы той же библиотеки).

Статус: **предложение облачной, ждёт слова автора** (вопросы — §8).

---

## 1. Из чего запись

| Поле | Что | Пример — «Копатель» |
|---|---|---|
| **Прозвище** | слово и его место: после имени («Марга Копатель»), перед («Косой Ждан»), вдвоём («Старый Ворон») | после: «Копатель» |
| **Кому** | условие по душе: спектр греха и добродетели, ремесло, оболочка, мораль, память; вес | жадность ≥ 40, живой или зомби (руки и спина), не Маг |
| **Не вместе с** | приметы, которые ему противоречат | «Брезгливый» |
| **Привычка** | в лагере: место (`CampSpot` или своё), движение (клип), звук, период; что меняет в мире | край поляны, клип Dig, лопата в землю; через раз — монеты в карман |
| **Строки** | почему так зовут, первая фраза, гибель — шаблон и оттенок по главному греху | «Копает везде, где встаёт лагерь…» |
| **Отклики** | на события лагеря (§4) — строка-шаблон или молчание | полено: «Полено-то моё. Я его нашёл» |
| **Голос в душе** | какой модуль её читает и что она меняет в решении | в набеге тянет к добыче: жадность громче у трупов |
| **Памятная вещь** | что остаётся после гибели (кодекс §10) | лопата |

Строки — **шаблоны** с подстановкой имени, падежа (`Grammar`), предмета; оттенок
по греху — одна из семи вариаций или нейтральная. Жадный копатель и унылый
копатель говорят о земле по-разному: «Земля всегда что-то прячет — надо только
не лениться» / «Копаю. Всё одно делать нечего».

## 2. Мерка качества — каждая примета обязана

1. **Видна сверху без клика** — привычка в лагере, а не строка в карточке.
2. **Объясняет прозвище** — посмотрел минуту и понял, почему его так зовут.
3. **Слышна** — звук привычки (43-SOUND §3): взгляд игрока бывает в другой стороне.
4. **Не врёт** — Косой мажет чаще (числами в бою), Счетовод называет точную сумму,
   Копатель правда находит. Соврала одна — игрок перестаёт верить всем (28-ORDERS, 26.10).
5. **Меняет хотя бы одно решение** — читается модулем души. Иначе это украшение,
   а «механика обязана проходить через личность» (CLAUDE.md).
6. **Гибель помнит её** — строка журнала и след в мире (яма без копателя).
7. **Работает в любом отряде** — у любого имени, грехи любого соседа; не опирается
   на конкретного «брата» — на связь из памяти.
8. **Без жребия** — та же душа даёт ту же примету и те же строки.

## 3. Как выбирается

* По душе, формулой: для каждой записи — насколько душа подходит (условия × вес);
  берётся лучшая, которой ещё нет в отряде. Отряд — без повторов.
* **Одна главная** (даёт прозвище и привычку) и иногда **одна малая** — только отклик,
  без прозвища (например «Считает чужое» у того, кто уже «Тихий»).
* **Нажитая.** Примета может прийти из памяти, как титул (`TitleManager`): потерял глаз
  в бою — «Одноглазый»; вынес раненого — «Носильщик». Порядок слов — как у титулов
  (`Naming`): нажитое прозвище переезжает вперёд.
* Женщин генератор не даёт (`unique_women`) — правило не трогается.

**Почему хватит 25–30.** В отряде из девяти приметы не повторяются. Человек уникален
сочетанием: примета × главный грех × добродетель × ремесло × оболочка × память.
Тридцать примет при семи грехах — двести десять голосов только по первым двум осям.

## 4. События лагеря, на которые отзываются приметы

Отклик ищется так: строка приметы → строка греха → молчание. Новое событие лагеря
сразу говорит голосами всех, у кого есть строка, — без правки чужого кода.

| Событие | Где сейчас | Сейчас |
|---|---|---|
| полено в костёр | `CampfireStoke` | по именам девяти |
| кошель Греховода изменился | `PurseCounter` | только «Лиска» по имени |
| знамя отряда | `RatBanner.Opinions` | по греху — уже как надо |
| карты: ход, выигрыш, проигрыш | — (п. 17 отзыва) | — |
| музыка у огня | — (п. 18) | — |
| гибель соседа | `SignatureDeaths` | по именам девяти |
| плата, долг | `CampLines` | по греху и положению — уже как надо |
| вернулись с вылазки | — | — |

## 7. План переноса — по шагам, демо не ломается

1. **Книга примет** (`Gameplay/HabitBook.cs`) — записи §1, правятся «прямо здесь», как
   `InspectTexts`. Девять демо получают приметы поимённо в составе (`SquadRoster`).
2. **Строки** — `Signature` читает книгу через примету воина, а не по имени.
3. **Привычки** — один механизм с параметрами вместо класса на человека: `DiggerHabit`
   и `CandleHabit` становятся записями (место, клип, звук, период, что меняет).
4. **Отклики** — `CampfireStoke`, `PurseCounter`, `SignatureDeaths` спрашивают примету.
5. **Генератор** — жатва, полка душ, вылазки дают примету по душе (§3).
6. **Проверка** — правило в `check.py`: имя человека в строке кода — только в поимённых
   списках, как `unique_women`. Иначе через месяц снова будет таблица по именам.

Шаги 1–4 демо видит одинаково: те же девять, те же строки. Отличие — десятый воин
больше не молчит.

## 8. Вопросы автору

1. Примета — запись библиотеки, человек получает её по душе — **да**?
2. Список §6 — что вычеркнуть, что добавить? Особенно: крыса-спутник у одного из «Крыс».
3. Нужна ли генерация примет **уже в демо** (жатва и полка душ дают новых людей),
   или в демо — только девять, а генератор — к основной игре?
4. Нажитые приметы (как титулы: потерял глаз — «Одноглазый») — да?
