## 3. Отложено до основной игры

* **Герой** — Морган (склоняется: нежить); Магистр — «рано думать».
* **Места:** лес «Поиск склепа», бой у склепа с отрядом Магистра, вторая
  миссия с развилкой.
* **Имена отрядов**: фиксированный боевой состав называет себя сам, особая
  связь, «вместе сильнее», своя тема (32-CAMP §12). «Крысы» — образец в демо.
* **Памятные вещи**, которые делают воинов личностями; знамя Хоря — образец.
* **Наказания:** шесть остальных (в демо — одно, Жадности); «отряд видит
  наказание» и позорные имена.
* **Музыка:** свои темы у каждого Греховода и отряда; «Обитель Ордена» — место
  Ордена; «Затаились» — под засады.
* **Достижения** — с магазином; «Крысы» — первое.
* **Продолжение пути:** Охотники натыкаются на склеп — прятаться дальше.
* **Шахматная доска вылазок** — после вехи 4 демо, если останется время.
* **ДЛС:** Безымянного (до демо по времени мира), демонов Богини Жизни.
* **Женские персонажи** — только уникальные и только в основной игре.
* Строка памяти «жатва — кража у Смерти»; голос Греховода — проба без голоса.
