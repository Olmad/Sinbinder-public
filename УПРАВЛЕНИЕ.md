# Sinbinder — управление

Ранняя альфа. Звука почти нет — только голоса реплик, синтезированные
кодом; половина красоты впереди. **Главное здесь — не картинка,
а то, что воины вам не подчиняются.**

## Самое важное, в одной строке

Ваш приказ — **не команда, а голос**. Внутри воина голосуют тринадцать
частей, и приказ участвует наравне с ними. Он может проиграть.

Когда воин решает по-своему, над ним вспыхивает **слово**, а под ним —
**причина**. Это и есть игра. Всё остальное — способ до этого дойти.

Есть один, кто слушается всегда, — **Греховод**, вы сами. Его ведёте
вы; отряд вас слушает — или нет.

## Ходить и смотреть

Игра начинается **сверху**. У каждого вида свои руки.

| | |
|---|---|
| **W A S D** | сверху — вести камеру; от первого лица — идти Греховодом |
| **край экрана мышью** | сверху — вести камеру (только когда курсор в окне) |
| **колесо мыши** | приблизить, отдалить |
| **V** | сменить вид: сверху ↔ от первого лица. От первого лица мышь вертит голову |

Сверху Греховод стоит, пока вы его не поведёте: выделите его щелчком
и укажите правой кнопкой, куда идти, — или нажмите **V** и идите сами.

## Выделять

| | |
|---|---|
| **ЛКМ** по воину | выделить. У ног загорается круг: **зелёный** — свой, **красный** — чужой |
| **ЛКМ** протянуть по земле | рамка: выделить нескольких своих. Врагов рамка не берёт |
| **Shift + ЛКМ** | добавить к выделению |
| **ЛКМ** мимо всех | снять выделение |

**Греховод** в рамку вместе с отрядом не попадает — чтобы «выделить
всех» не уводило и вас. Обведите рамкой его одного или щёлкните
по нему — и он выделен.

**Врага можно выделить** — посмотреть, кто он, — но приказывать ему
нельзя.

## Отдавать приказы

Приказы уходят только своим живым.

| | |
|---|---|
| **ПКМ** по земле | идти туда |
| **ПКМ** по врагу | атаковать. Только живого и видимого: врага в тумане не достать |
| **Shift + ПКМ** | **отходить**. Это другой приказ, а не «иди туда»: отход звучит для характера иначе, и воин может исполнить его по-своему — побежав |
| **M / T / X** | идти / атака / отход — затем щелчок, куда (как в Warcraft 3). «Атака» по земле — идти туда и бить всех по дороге. ПКМ — передумать |
| **P** | патруль: затем щелчок — ходить отсюда туда и обратно, пока не снимут |
| **H** | держать строй |
| **G** | обороняться |
| **C** | снять приказ (cancel) |
| **1 … 6** | установка отряду: без указаний, в атаку, прикрывать своих, беречь себя, собирать добро, держаться приказа |

Оборона на **G**, а не на D, нарочно: WASD принадлежат камере целиком.

Все эти приказы есть и **кнопками** — справа внизу, пока выделены свои.
Наведите на кнопку: подсказка скажет, как приказ звучит для характера.

Выделенный **Греховод** идёт по правой кнопке сразу, без спора;
правой кнопкой по врагу — идёт на него.

## Туман войны

Карта сначала чёрная. Что видят ваши воины и Греховод — видно как есть;
где они побывали и ушли — остаётся серым, и **врагов там не видно**.
Край карты, куда бежать, открывается серым сам.

## Руки и душа

| | |
|---|---|
| **E** | забрать душу павшего. **Торопитесь** — она угасает, и от того, насколько вы успели, зависит, что от неё останется |
| **F** | взаимодействовать: совет у стола с шаром, устройство в склепе. От первого лица, глядя на воина рядом, — заговорить: он ответит по своей душе, и ниже откроется обмен. Слева пять мест воина (оружие, щит или второе оружие, шлем, броня, пояс), справа мешок Греховода. Щелчок переносит вещь — а воин может не взять или не отдать. На занятое место — замена: прежняя вещь вернётся в мешок |
| **Tab** | следующая ячейка сумы (строка клавиш видна над сумой) |
| **R** | переложить: из руки в ячейку и обратно |
| **I** | снаряжение выделенного воина — посмотреть издали. Передают только из рук в руки: подойти и F |

## Смотреть глубже

| | |
|---|---|
| **O** | ступени ясности — сколько игра о себе рассказывает |
| **Escape** | меню паузы: сохранить, настроить экран и поворот взгляда, выйти |
| **F5 / F6** | быстро сохранить / загрузить |
| **F9** | слоты сохранений |
| **~** | консоль. `помощь` — список команд, `aos` — съёмка для роликов |

## Если Греховод погиб

Игра окончена: экран «Греховод пал», две кнопки — **начать сначала**
или **выйти**. На этом экране F5, F6 и F9 не работают — начните
сначала, там и запись. В игре с обязательством запись стирается:
переиграть смерть нельзя.

## Чего в игре нет и не должно быть

**Цифр.** Ни очков, ни весов, ни процентов — только слова. Если вы
увидели число, это ошибка, и о ней стоит сказать.

## Что стоит попробовать

1. Прикажите отряду держать строй перед боем — и посмотрите, кто
   послушается.
2. Дайте жадному воину что-нибудь ценное в руки и повторите приказ.
   Вещь в руках спорит у него в голове.
3. Не торопитесь забирать душу — и посмотрите, кем поднимется тот,
   за кем пришли поздно.
