## 1. Единственный критерий успеха недели

Есть **один настоящий прогон Unity на зафиксированном SHA** (либо конкретный воспроизводимый blocker Unity Editor/Player), полноценный журнал `[AOS-5M]` и `[СОН QA]` по доступной части сна, **список проблем с доказательствами**, ранжированный по P0/P1/P2, и **одна** согласованная задача W02, обоснованная реальным эффектом для игрока.

Демо уже было проходимо автором раньше. Эта неделя не пытается заново «сделать игру играбельной». Она превращает личное знание автора в воспроизводимые данные, чтобы пять сессий не исправляли разные воображаемые проблемы.

**Более сильный успех:** 11/11 сценариев W01 имеют статусы PASS/FAIL/BLOCKED/NOT TESTED, но полный набор **не обязателен** для первой диагностики при ограниченном времени. Принципиально нельзя превращать NOT TESTED в PASS.

## 7. Явное исключение автора 17.11 — обучение короткому Суду после полного

**Автор прямо запросил реализацию** короткого Суда. На 17.11 отдельное исключение больше не требуется: общая заморозка снята, а работа над Судом продолжается по контролируемому процессу. Сам Суд по-прежнему `IMPLEMENTED / NOT ACCEPTED IN UNITY`.

**Реализовано в коде на feature/server-prototype, Unity ещё не проверена:** после первого полного Суда сон один раз предлагает выбор автоматических показов, затем проигрывает **настоящий короткий `SoulCourt.Convene(brief: true)` того же решения**, без нового `AOS.Decide()`. Выбор сохраняется в `PlayerPrefs` и доступен позже в паузе («Автоматический Суд души»). При отключении автоматических Судах `CourtCaller` больше не созывает их в важные моменты, но ручной `U / Shift+U` и обязательный учебный Суд работают; короткий пример показывает независимо от выбранного ответа. Headless Unity автоматически пропускает только интерактивный вопрос, но пытается выполнить сам короткий показ; никаких фиктивных кликов и запомненного ответа. Строки добавлены в `en.txt`.

**Обязательный W01 ретест нового изменения:**
- [ ] Новый профиль / `PlayerPrefs` без `sinbinder.court.choice.made`: полный Суд действительно виден, после него появляется плашка **перед** короткой демонстрацией. Отдельные временные отметки `[AOS-5M] short_court_choice_opened`, `short_court_preview_requested`, `short_court_preview_finished`.
- [ ] Выбор «Показывать автоматически»: `Preferences.Court=true`; после урока важный отказ может вызвать `CourtCaller` (с учётом порога и cooldown). Нет повторного голосования AOS за счёт демонстрации.
- [ ] Выбор «Не показывать автоматически»: учебная короткая демонстрация **всё равно** завершается, автоматический вызов не происходит, ручной просмотр `U` и `Shift+U` сохранён. Настройка переживает перезапуск, меняется через Esc → «Автоматический Суд души».
- [ ] Повтор новой игры на том же профиле **не показывает вопрос снова**. Для чистого теста использовать резервный профиль или **сохранить и вернуть** исходные PlayerPrefs; не удалять чужие настройки без резервной копии.
- [ ] Игру можно закрыть во время выбора без вечной паузы после повторной загрузки. Проверь 1280×720 и другой размер; проверить английский перевод новых строк.
- [ ] Batch `DreamWalkthrough`: без ожидания мыши и без `CourtChoiceMade`, проверка итогового `Held`/длительности, чтобы новая короткая сцена не стала ложным успехом. **Наличие исходного CI не эквивалент Unity PlayMode.**

**Критерий принятия:** полная сцена → плашка → короткий Суд → обычный дальнейший сон, выбор сохраняется, `U` работает при выключенной автоматике, виден реальный исход AOS, не появляются новые P0. До ручной проверки: `IMPLEMENTED, NOT ACCEPTED`.
