## Классы
S — конкретное расхождение в исходниках/структуре; runtime и достижимость не автоматически доказаны. H — гипотеза/неполная достижимость, нужен тест. D — известное ограничение, семантика или баланс требуют авторского решения (не автоматически дефект). Q — пробел/контракт тестирования. N — новое авторское требование, не старая регрессия. Для смешанных исходных групп класс отражает основной тип, подробности в исходных отчётах. P0/P1/D у пакета — предлагаемая последовательность и важность, не автоматическая переклассификация исходных приоритетов. F06 содержит P0 R12-01 и должен быть блокером поднятия.

Для каждого ID: исходная формулировка и источник, классификация, минимальный контрпример/договор, production patch SHA или обоснованное N/A, тест до/после и мутация, фактические ассеты, уровни L0–L4, независимая проверка exact SHA, не открытые риски. Не подменять ожидание Unity зелёным shim. Общие тесты по §94. Ноль открытых применимых P0/P1 и отсутствие необследованных обязательных элементов, авторская приёмка. После каждой пачки обновлять исходные ID, а не только счётчик пакетов. Игровые исходники не изменены; Unity/CI не запускались. Не является завершением полной проверки AOS.

## Проверка узких исправлений 26.11

- **R5-01 / F09.** `SoulData` выдаёт описание соответствующего полюса при прежних порогах. `SoulDescriptionChecks` выполняет реальный C# и проверяет семь спектров на русском и английском. На исходном индексе воспроизведена инверсия. Доступность экранов и R5-07 остаются отдельными проверками.
- **R8-01 / F17.** `HarvestableBody.GatherLoot` переносит взятое в руки, карман или кошель, сохраняя отклонённое на источнике. `ExecuteLoot` записывает память только после подтверждённого переноса. Стенд проверяет перенос через заглушки Unity и получателей. Фактический ход боя в PlayMode и остальные пункты F17 открыты.
