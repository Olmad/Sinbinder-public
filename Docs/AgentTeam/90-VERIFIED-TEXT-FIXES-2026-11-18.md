## Сделано

1. **`Assets/Scripts/Gameplay/Whisper.cs`:** все семь предложений и реакций больше не ссылаются на несуществующих свидетелей, незасвидетельствованные оскорбления, Каргана, котёл и невозможную гарантированную безопасность до утра. Новый Похотливый Шёпот: «Направь своё желание на этот приказ» → «Я выбираю. Сделаю». Сохранены семь грехов, задержка, выбор действия, ревизия приказа и правила согласия.
2. **Жадность, три монеты:** исходная система списывала `GreedCoins=3` из кошеля игрока, **не зачисляя** их в карман воина. Теперь сначала требуется успешный `bag.SpendGold(GreedCoins)`, затем `w.Pocket(GreedCoins)`, который также синхронизирует `SquadRoster` для сохранений, только после этого применяется `Consent`. Уточнены реплики при 0–2 монетах и при изменении приказа. Это **реальное минимальное исправление механического последствия** обещания, поэтому требует особой Unity-проверки сохранения/баланса; никакого нового отдельного механизма денег не создавалось.
3. **`SoulCourtReasons.cs`:** явно парные реплики Добродетели для мужчины и женщины (исправлены «А добрый»/«грешник» для женщин); «полный кошель» заменён на проверяемое `PocketGold>0` и нейтральную формулировку; объяснение Memory больше не утверждает незаписанные личные спасения/предательства.
4. **`DreamTutorialDirector.cs`:** при повторном приказе больше не говорится, что «единственная причина исчезла», когда фактически был только новый вердикт. Сохранены два исхода и подсказка о наведении мыши.
5. **`EncounterLines.cs`:** убрано необоснованное «твои склянки на вкус пробовал»; новая вопросительная реплика к алхимику не утверждает личную общую историю.
6. **`Assets/Resources/Lang/en.txt`:** обновлены EN переводы всех изменённых фраз; новые ключи для двух женских/мужских вариантов Суда и различных причин несостоявшегося уговора. Дублирующаяся после объединения по родам строка обучения удалена.
