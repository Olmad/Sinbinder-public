## Подтверждённые свойства
SoulManager.Update действительно меняет качество, а не только начальное состояние. При стандартном 60s FadeTime без улучшений: Shock t<24s; Acceptance 24<=t<42; Fading 42<=t<54; Dissolved 54<=t<60; затем исчезновение. SoulDecay округляет спектры с коэффициентами 1/.85/.55/.20. KeepsMemory для Shock/Acceptance, KeepsPerks кроме Dissolved. Пол/профессия сохраняются. SoulHarvester.TryHarvest проверяет SinbinderPlayer, Team.Player и живость даже через HarvestNow; не выдавать наличие компонента у воина за разрешение жатвы. Смерть героя исключена. Повторный death event защищён, огонёк удаляется по ссылке именно этой души. SatchelHands возвращает душу в банку при неудачном переносе в руки. SoulCustody сохраняет банки/руки/устройство и проверяет дубли ID. ShellChoice задаёт допустимую силу связывания по качеству; не менять пороги без автора. Все свойства требуют сквозного Unity теста.
