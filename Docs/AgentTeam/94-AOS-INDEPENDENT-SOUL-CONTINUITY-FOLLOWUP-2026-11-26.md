## Независимый контроль
A. Две настоящие души с одним Kin, ещё две с другим; в каждом качестве сравнить семь спектров, Kin, биографию, перки, титул, ID души/тела, реальные адресные воспоминания. Успех при Shock не должен зависеть от обхода штатной жатвы.
B. Одна свежая собранная душа → банка → полка → руки → устройство → save/load на каждом этапе → поднятие → запись roster → новый процесс → автоэкспедиция. При каждой границе сравнить фактические поля и AOS голоса. Отрицательные контроли: убрать SetKin/копию Seed/перенос адресов; тест обязан краснеть.
C. Отдельно боевое поднятие (все силы, 1 HP) и стационарное (полное HP) по §20, отказ без расхода, две банки, повторная смерть, полная сумка. Не реализовывать новый контракт в документационной ветке и не считать учебный shortcut доказательством штатной механики.
