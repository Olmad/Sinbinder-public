## 2. P0 — ветка не компилировалась в Unity (исправлено)

- `Gameplay/CardTable.cs:554,559`: `IReadOnlyList<int>.Contains` без `using System.Linq` (CS1061).
- `Gameplay/SquadGear.cs:202`: `Mathf` без `using UnityEngine` (CS0103).

Ошибки появились 11.11 (коммиты по картам и снаряжению) и прожили 5 дней. Всё это время семь CI были зелёными: **CI не компилирует игровой код так, как Unity.** Поэтому шаг T01 плана 55 провалился бы первым же действием автора.
Исправление — две строки `using` (`538901d2`).

**Правило для всех ролей:** «CI зелёный» ≠ «Unity собирает». Перед заявлением G3 нужна компиляция модулями Unity. Её делает старшая сессия или автор.

## 4. Хорошее — оставлено как есть

- **Damageable / Bodyguard.**
  - Отсекают NaN, ∞ и отрицательный урон; лечение и рана тоже защищены.
  - Перехваченный удар больше не уходит в `Bodyguard.Absorb` повторно: двое раненых, охраняющих друг друга, давали два ложных спасения.
- **Суд по решению** показывает голоса, записанные при решении (`LastDecisionBallot`), без пересчёта на нынешние HP и эмоции. Это и есть «судьи = настоящие голоса».
- **`ActuallyObeyed`:** «послушался» — только при `ObeyCommand`.
- **Сон, повтор приказа:** один вызов `mind.Decide()` через 1,2 с, выход через 6 с. Больше не застревает.
- **`DreamRoad`:** у лезвия косы отдельные вершины для обратной стороны, нормали больше не гасят друг друга.
- **`TooltipViewportFit`:** подсказка воина влезает в экран и не сжимается накопительно.
- **LAN:** десяток защит — терминальное событие важнее буфера, `PreflightEnvelope`/`PreflightShape`, отмена очереди при закрытии. Соло не задевают.
- **`build-game.ps1`:** строже проверяет сборку. BOM на месте, синтаксис PowerShell 5.1 без ошибок. Минус: имена папок сборок теперь с хвостом GUID из 32 знаков.
- **`[AOS-5M]`:** безвредные отметки времени для вечернего теста.

**Замечание.** `AOSWarriorWrapper` теперь копирует `DecisionContext` и список памяти на каждое решение каждого воина. Это лишний мусор для GC, на демо не критично. Если в бою будут фризы — смотреть сюда.
