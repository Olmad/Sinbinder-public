## Положительное
Stage.Deciding проверяет ревизию приказа, не подставляет вердикт при отсутствии решения; Judge передаёт записанный бюллетень, Completed проверяется перед переходом к краткому Суду; Contrast не утверждает причинность только из смены ответа. TryRebind/Reraise снимают банку после успешного создания. Practice считает встреченный блок у чучела, не только нажатие кнопки. Печати больше не пропускают одного по таймеру и исключают мёртвых/чужих. Подсказка альтернативы не называет задержку отказом. NOCHASE batch отключает самостоятельную погоню только для заданной ветки; маркировать как управляемый тест, не естественный исход.
