# 88 — TOTAL TEXT AUDIT / принудительная приостановка UX-спринта

**Решение автора:** 18 ноября 2026, немедленно. **Статус:** FULL TEXT AUDIT REQUIRED / **NOT ACCEPTED**.  
**UX-спринт 17–23.11:** **ОТМЕНЁН И ПРИОСТАНОВЛЕН**. Не возобновлять UX/исследования игровой идентичности/разработку новых механик ни по расписанию, ни автоматически 24 ноября, пока каждый из пяти специалистов не завершит свой **независимый полный обход** и автор прямо не разрешит возврат.

## 1. Почему и что теперь считается работой

Игроко-видимые тексты содержат неподтверждённые факты: в \u0060Whisper.Words\u0060 Похоть безусловно произносит «Она смотрит» без соответствующего персонажа в демо, а QA и логические сессии многократно пропускали её несмотря на прямое требование причинности. Существовавший «аудит диалогов» 11.11 ограничивался частью подсистем, но его качество путали с покрытием всех текстов. Никакие отчёты «проверено» без перечня проверенных строк теперь не принимаются.

**Текущая область:** ВСЁ, что игрок может прочесть или услышать, независимо от того, реализовано ли текстом в C# literals, таблице/базе данных/ScriptableObject, Unity сериализации, импортированном asset, переводе или UI. Диалоги, Шёпот, Суд, подсказки, описание перков/предметов/карточек/экспедиций/настроек, лор, вступление, концовки, бои, лог, уведомления, ошибки, локализации RU и EN. Сравнить текст с реальным условием появления, памятью, персонажами, миром, причинностью и механикой.

## 2. Важное разделение: исчерпывающая опись ≠ полная проверка

Построена первая программная опись **всего Git-дерева** на SHA \u00603b642a701a990ace58556b2afc2de04fd517b351\u0060. В Git-дереве **2855 blob-файлов**, из них **582 предварительных кандидатов текстоносителей** среди Assets/StreamingAssets/Packages/ProjectSettings с расширениями C#, TXT, JSON, CSV, TSV, XML, YAML, ASSET, PREFAB, UNITY, UXML, USS, INK, YARN, PO, STRINGS, BYTES. Исходный список с точными путями, размерами, SHA и начальными статусами см. [88-TEXT-SOURCE-INVENTORY-2026-11-18.tsv](88-TEXT-SOURCE-INVENTORY-2026-11-18.tsv).

Подсчёт кандидатов: **464 C#**, **7 TXT**, **19 JSON**, **42 ASSET**, **38 PREFAB**, **12 UNITY**. Бинарные картинки, текст на текстурах, строки шрифтов/импортов/Addressables и генерируемые на лету значения ПОКА НЕ ПОДТВЕРЖДЕНЫ и должны быть явно отражены в итоговой инвентаризации. Технические строки (путь, Guid, Unity-property, имена методов) отличать от пользовательских. Наличие файла в описи — \u0060UNINSPECTED\u0060, а не \u0060PASS\u0060.

**QA обязан сверить охват и обнаружить источники, пропущенные фильтром расширений/Assets**. Любой отчёт «все строки проверены» без проверки дополнительно подгружаемых ресурсов и текстов внутри Unity сцен недостоверен.

## 3. ПЯТЬ НЕЗАВИСИМЫХ ПОЛНЫХ РЕВИЗИЙ, НЕ РАЗДЕЛЕНИЕ НА ПЯТЬ ЧАСТЕЙ

Каждая из пяти включённых почасовых сессий получает **тот же полный инвентарь** и независимо просматривает весь игровой текст, а не только свою старую специализацию. Пересечение обязательно: оно нужно, чтобы один проверяющий мог поймать пропуски другого.

- **№1 :23** — полный проход A: смысл, существование NPC/предметов/свидетелей, игровое положение, реакция, атмосфера, знания говорящего.
- **№2 :41** — полный проход B: смысл для игрока, буквальная достоверность, понятность, цена приказа, соответствие действия и объяснения, ложный причинный вывод.
- **№3 :11** — полный проход C: откуда берутся факты, памя​ть, отношения, ресурсы, условия вызова, RU/EN, YAML/asset/scene, недоступные источники.
- **№4 :33** — полный проход D: все игроко-видимые строки с проверкой соответствующих C# условий, переводов, фиксацией воспроизводимых контрпримеров. ЕДИНСТВЕННЫЙ владелец мелких безопасных правок настоящих текстов/контекстных условий, отдельными подтверждёнными патчами.
- **№5 :53** — полный проход E + QA: независимая перепроверка всех областей, точные значения covered/total, конфликтующие выводы, источники истины, невозможность ложного COMPLETE. QA принимает малые патчи только на точном SHA.

Сессии сохраняют **одно почасовое расписание каждая**. Не менять ветки, PR, main, work-table. Новые механики, переустройство UI, маркетинговый анализ, продолжение UX-спринта, новый визуал и мультиплеер **заморожены**. Только подтверждённая безопасность данных/критическая регрессия игры может прервать аудит; решение об этом фиксирует QA.

## 4. Карточка аудита КАЖДОЙ строки

| Поле | Обязательное значение |
|---|---|
| Путь/ID | Точный файл, ключ или метод, blob SHA / source lines |
| Текст | Дословная видимая реплика, строка EN, контекст говорящего |
| Условия появления | Где, когда, кто, кому, кем вызывается |
| Утверждения | Указанный NPC/пол/предмет/прошлое/смерть/воспоминание/награда/эффект |
| Источники | Реальные данные игры и условия проверки правдивости |
| Контрпример | Конкретный доступный контекст, в котором строка ложна/нелепа |
| Реакция | Ответ второго персонажа и реальный исход, не выдуманный |
| Статус | PASS / FAIL / NEEDS CONTEXT / UNREADABLE / UNINSPECTED |
| Доказательство | Код, fixture, negative-test, локализация, SHA; Unity явно отдельно |
| Исправление | Минимальная коррекция, риск, ответственный, статус |

Проверять также орфографию, стиль, ясность, грамматику рода, повторения, русско-английскую согласованность. Не исправлять авторские формулировки без конкретного подтверждённого изъяна или необходимости восстановления смысла.

## 5. План контроля без участия автора

1. Каждый агент идёт по всему инвентарю независимо, отмечая checked/reviewed, точно подтверждённые FAIL, UNKNOWN и непрочитанные источники. Не выдавать только список файлов за проверку текстов.
2. :53 ежедневно контролирует 5 отдельных счётчиков фактического охвата, не кол-во запусков/коммитов. Не давать завершающий статус по общему резюме или чужим словам.
3. :33 исправляет только доказанные ошибки малыми изолированными патчами; :53 независимо проверяет соответствующие ветки и перевод. CI/Unity источники состояния различать.
4. После пятого полного прохода QA обязана вывести несогласованные выводы и продолжить до устранения разногласий; повторно проверять **исправленные** строки на новой версии. Все источники, не доступные через GitHub (бинарные ассеты, сгенерированный текст, Unity-only) честно отмечаются как `UNKNOWN`, а не `PASS`.
5. Еженедельный реальный Unity-прогон автора — только для 1–2 самых важных сценариев. Не требовать ежедневно тестировать руками. Возврат к UX только по **прямому решению автора** после предъявления карты покрытия, пяти независимых отчётов и списка остаточных неизвестных.

## 7. Определение «максимально полная проверка завершена»

Только когда доступны:
- Git-список всех источников текстов + динамических генераторов/бинарных exceptions; каждая player-facing строка получила ID и проверена в каждом из пяти независимых проходов.
- Полная таблица FAIL с воспроизводимыми контрпримерами, приоритетами, исправлениями и повторными проверками, а не пять пересказов.
- Русские/английские строки и условия вывода проверены. Все оставшиеся неразрешимые без Unity/ассета случаи отмечены `UNKNOWN`, количество и риск, а не скрыты.
- QA указывает точный SHA и фактический уровень проверки, не повышает до runtime за source-тесты.
- Автор лично подтверждает готовность вернуться к UX. **Пока этого нет, UX-спринт ОСТАНОВЛЕН.**

**Эта карточка — приказ и реестр исходников. Пока ни один полный проход 582 файлов не объявлен завершённым.**
