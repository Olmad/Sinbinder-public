# Музыка — все записи

Автор, 23 октября: «думаю, что все мелодии стоит сохранять». Здесь лежит
каждая записанная мелодия проекта, которой нет в игре, — послушать
и выбрать. Что звучит в игре, лежит в `Assets/Resources/Music` и здесь
не повторяется. Папка вне `Assets`: в сборку игры она не попадает.

Ноты всех тем — в `Tools/music`, разбор и замеры — `Assets/Scripts/docs/43-SOUND.md`.
Записи сделаны одним проходом для слушания; петлю для игры собирают
командой из `43-SOUND.md` («Как пересобрать записи игры»).
