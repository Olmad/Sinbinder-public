## «Крысы» — тема отряда Безымянного, сюита (`Tools/music/rats.py`, 23 октября)

Автор: «Крысы — тема отряда Безымянного, потому что они сбежали и теперь
пытаются просто выжить, бегая по углам, прячась от опасности. И отдаёт лёгким
лесом под стать окружению» и «нужен комплект мелодий этой темы. Хотя бы чтобы
я слушал и мне было здорово». Восемь пьес — одна ночь отряда, папка `Крысы`.
Везде мотив автора (фагот ре–фа–соль-диез–ми–ре) и лесной состав.

| Файл | Что |
|---|---|
| 01 У огня | ночь в лагере: мотив вдвое медленнее у фагота, гобой; кончается ре мажором — живы |
| 02 Тропа | идут лесом: пиццикато шагом, флейта внизу — птица; в середине поляна фа мажора |
| 03 Затаились | опасность рядом: мотив у кларнета обрывается на соль-диез, сердце литавр |
| 04 Удирают | бегом: мотив вверх по малым терциям — круг без выхода, потом вниз — нашли щель |
| 05 Отбиваются | стычка; есть петля — кандидат в первую волну набега |
| 06 Делят добычу | «ум-па», фагот пересчитывает мотив по монетке, кларнет хихикает |
| 07 Крысиная песня | на три счёта, когда никто не гонится; мотив становится напевом |
| 08 Колыбельная | перед рассветом: соль-диез уходит в ля — бежать не надо, хотя бы до утра |
