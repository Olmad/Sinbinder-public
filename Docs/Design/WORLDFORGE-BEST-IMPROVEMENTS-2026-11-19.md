## Сохранено из объединённого WorldForge

Вся существующая функциональность редактора из объединённого PR #6: рельеф, раскраска материалов, растительность/биомы, выделение и групповое редактирование объектов, импорт ассетов в Unity Editor, ECA-триггеры, безопасное сохранение и восстановление, подсказки отсутствующих моделей, исправленная сцена с видимым экраном. Автор подтвердил в реальной Unity, что чёрный экран исправлен. Это подтверждение не означает приёмку остальных подсистем редактора.

## Новые конкретные улучшения в этой ветке

### 1. Прямое перемещение выделенной группы мышью

В режиме **«Выделить»** сначала выберите одну или несколько обычных моделей (Shift+ЛКМ, рамка, Ctrl+A). Затем протяните **ЛКМ от уже выделенного объекта** до нужной позиции и отпустите. Вся выделенная группа перемещается с сохранением взаимных расстояний и учётом текущей сетки. Один drag = одна операция Undo/Redo. Если любой предмет уйдёт за край, изменение отменяется целиком. Склепы, регионы, события и связанные ссылки триггеров не изменяются.

**Ограничение:** изменение применяется при отпускании кнопки, пока без динамического 3D gizmo и ghost preview. Shift+drag сохраняет режим рамки выделения. При отмене жеста за границами рабочей области карта не изменяется.

### 2. Центрирование камеры на выделении

**Ctrl+F** или кнопка «К выделению» в режиме выбора. Для нескольких объектов камера центрируется по общему центру; для одиночного склепа, области и другого поддерживаемого элемента по его позиции. Содержимое карты не изменяется.

### 3. Экстренное сохранение копии

**Ctrl+Shift+S** вызывает уже существующее безопасное «Сохранить копию» в новую JSON-карту, не перезаписывая исходный файл. **Ctrl+S** по-прежнему обычное сохранение с защитой от изменений на диске.

### 4. Все ошибки валидации доступны автору

Кнопка «Проверить карту» теперь сохраняет полный набор результатов, показывает первые три проблемы и общее количество. Кнопка «Копировать список ошибок» переносит **все** ошибки в буфер обмена, не только первую. При следующем редактировании / Undo/Redo прежние результаты сбрасываются. Неудачное сохранение также открывает список ошибок. Удалено дублированное сообщение об одной и той же ошибке рельефа.

## Доказательства

- `Tools/map-editor/Program.cs`: проверка движения нескольких объектов со snap, атомарного отката при выходе за границы, Undo/Redo, сохранности склепов/регионов/триггеров; камера группового фокуса; все ошибки валидации и сброс кэша после изменения.
- `Tools/map-editor/UnityStubs.cs`: дополнен API-test shim для Ctrl+F.
- `.github/workflows/map-editor-smoke.yml`: компиляция настоящего C# кода редактора с тестовыми Unity API.
- `.github/workflows/map-editor-visibility.yml`: source-level защита исправления чёрного экрана.

**Уровни проверки:** C# тесты на Unity shim НЕ равны реальной Unity PlayMode. Обязательна ручная проверка переноса, визуальных маркеров выделения, сохранения, коллайдеров и NavMesh в Unity, прежде чем переносить ветку в рабочую.

## Предлагаемое продолжение (ещё не реализовано)

- Живой gizmo/ghost preview во время drag, перетаскивание по осям X/Z и точное числовое позиционирование.
- Стабильный ввод десятичных полей в инспекторе с подтверждением Enter, без перестроения карты на каждую набираемую цифру.
- Полноценная панель диагностики с ссылками от ошибки к объекту/триггеру.
- Тестовый запуск карты из редактора с возвратом к несохранённому снимку.
- Пакеты пользовательских ассетов для запуска на другом ПК без Unity Editor.
- Более развитые безопасные сценарии: типизированные переменные, условия и действия с тестовой симуляцией, без выполнения произвольного кода.

Эти пункты остаются планом и не могут выдаваться за готовые функции. Проектный UX-спринт как отдельное расписание не возобновляется автоматически.
