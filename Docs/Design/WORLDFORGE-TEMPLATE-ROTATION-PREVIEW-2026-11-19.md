# WorldForge: поворот композиций и предпросмотр границ (19.11.2026)

**Основа:** `feature/worldforge-object-templates-2026-11-19` / PR #9.  
**Изменения:** отдельная ветка `feature/worldforge-template-rotation-preview-2026-11-19`; не сливать до проверки совместимости с локальным Codex.

## Пользовательский сценарий
1. В каталоге шаблонов выбрать композицию из обычных объектов.
2. Перевести курсор на карту: полупрозрачные круги показывают **центры каждого объекта** будущей композиции, а не обещают точные габариты его модели. Круги располагаются на высоте рельефа.
3. Поворачивать композицию **Q/E**. Меняются взаимные положения объектов вокруг общего центра и собственный Yaw каждого объекта.
4. Зелёные маркеры обозначают попадание точек установки в границы карты и доступность слотов по числу моделей/правил. Красные обозначают выход за границы или превышение числовых лимитов. Доступность конкретных префабов/материалов проверяется **при фактической вставке**.
5. ЛКМ вставляет группу одной транзакцией. События F получают новые идентификаторы и корректно переназначенные цели. Esc прекращает размещение.

## Защита данных
- Предпросмотр не записывает `MapData`, не меняет выбор и не добавляет Undo. При уходе курсора на UI или выходе из режима маркеры скрываются; при уничтожении редактора удаляются также их материалы.
- Поворот выполняется в double-проекции по правилу Unity +Y, затем безопасно приводится к float; значения NaN/Infinity отклоняются. Вставка использует *те же координаты*, что и предварительная проекция.
- Проверка всех границ и лимитов идёт до добавления первого объекта или правила. На ошибке карта не изменяется.
- Нулевой поворот сохраняет прежнее размещение; внешний формат шаблонов версии 1 не меняется.
- При каждом клике исходный JSON перечитывается, так что повреждение/удаление файла не обходится старым кэшем для размещения.
- Ни числовые поля Enter/Esc/Undo, ни временный playtest/return локального Codex не менялись.

## Проверки
- Компилируемые smoke-утверждения `Tools/map-editor/Program.cs`: 90° и −90°, собственные углы, совпадение ghost/вставки, сохранение ссылок F, запрет NaN/Infinity, границы, отсутствие побочных изменений предпросмотра, единый Undo/Redo на повернутую группу.
- Обязательная ручная Unity-приёмка: шаблон с тремя разнонаправленными объектами и одним F-событием; вращение Q/E на плоской/неровной карте; цвет маркеров возле краёв; проверка предпросмотра при смене масштабирования сетки; отмена Esc; Undo/Redo; пропавшая модель; повторное чтение изменённого файла.
- `dotnet` smoke в GitHub Actions отделён от реального запуска Unity. Без ручного PlayMode нельзя объявлять визуальный результат проверенным.
- Новые русские UI-строки являются изменениями к отдельному текстовому аудиту, их не следует считать автоматически принятыми.
