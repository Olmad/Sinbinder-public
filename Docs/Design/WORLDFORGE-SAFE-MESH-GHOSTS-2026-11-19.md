# WorldForge: безопасный 3D-предпросмотр композиций

Дата: 19.11.2026. База: общий WorldForge после PR #8, #9 и #10, коммит `279356a`.

## Реализовано

- При выборе шаблона редактор один раз строит 3D-предпросмотр геометрии моделей. Он переносит только `MeshFilter` и `MeshRenderer` с их иерархией локальных трансформаций. Материалы берутся из исходных моделей; назначенный пользователем материал имеет приоритет, как при обычной расстановке.
- Превью следует за курсором вместе с сеткой, положением на рельефе и поворотом Q/E. Сам prefab **никогда не инстанцируется** в качестве ghost: его MonoBehaviour, коллайдеры, аниматоры, свет, частицы и другие компоненты не копируются.
- Полупрозрачные маркеры центров сохраняются для проверки границ. Отсутствующие ассеты теперь делают маркеры красными, ещё до попытки вставки.
- Для сложных префабов, SkinnedMeshRenderer, отсутствующей статической геометрии или превышения лимитов создания ghost сохраняется прежний круговой предпросмотр. Это не сообщение об отсутствии *самого* ассета.
- Лимит не более 48 узлов на модель, 256 узлов на всю группу. Никаких сеток или материалов модели не модифицируется.
- Кэш моделей и их исходных ссылок создаётся при выборе/перезагрузке шаблона: движение мыши не вызывает дополнительные `Resources.Load`. Кэш удаляется при отмене установки Esc, выборе нового шаблона, повторной загрузке JSON и уничтожении редактора. Позиционирование не меняет `MapData` и Undo.
- В боковой панели режима шаблона есть переключатель «3D-предпросмотр моделей». Если он выключен, остаются только маркеры границ. Поворот отображения нормализован тем же способом, что и конечный Yaw поставленного объекта.
- Формат `MapObjectTemplate` не менялся. Нет новых скриптов внутри игровых карт, нет изменения механик и задач локального Codex.

## Проверка

- `Tools/map-editor/MapEditorChecks.csproj` компилирует реальный `MapTemplateGhost.cs` и `MapEditor.cs` с Unity API doubles.
- В тестах проверяются дочерние MeshFilter, сохранение ссылок на материалы и геометрию, отсутствие скриптов и коллайдеров, лимиты, запасной режим, создание и перемещение редакторского preview.
- Проверка видимости и компиляции GitHub Actions важна, но не заменяет отрисовку в Unity. Для Unity: проверить несколько настоящих FBX с вложенными MeshRenderer, повернуть Q/E, поставить около края карты, проверить материал пользовательского объекта, отмену Esc, многократную смену шаблона и отсутствие оставшихся ghost-объектов.
- Динамические тексты шаблонов остаются частью отдельного текстового аудита; новых сюжетных строк не добавлено.

## Ограничения

SkinnedMeshRenderer не копируется, анимация не воспроизводится. 3D ghost отображает сохранённую статическую геометрию и материалы, но не эффекты скриптов. Наличие ассета не гарантирует его корректный художественный результат; превью не заменяет PlayMode.
