# 16 октября — Надпись: шипастая пешка на черте

Автор, 16 октября: «можно куда-нибудь впихнуть шипастую пешку — теперь она символ нашей системы, а может и игры». Под словом «Sinbinder» — черта, на ней шипастая пешка: пешка Бога Смерти, у которой проросла своя воля (голова — шар с шипами, шипы из воротника, колючки по бокам). Ромб с середины черты ушёл на её концы. Слово поднято выше, чтобы пешка не легла на буквы; черта кончается выше места девиза. Кадр — предпросмотр картинки облаком (размер и место девиза — как в открытии), не из игры: кадр из игры снимет D.
