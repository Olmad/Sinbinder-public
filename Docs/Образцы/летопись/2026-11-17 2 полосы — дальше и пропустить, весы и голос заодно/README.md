# 17 ноября — Полосы 17.11: «ЛКМ — дальше» и «Esc — пропустить»; в миг с убийцами вид сверху посередине; строка сна называет тот же голос, что весы

Автор 17.11: «кнопку для проматывания и кнопку для полного пропуска диалога». В правом углу верхней полосы — «ЛКМ — дальше» и «Esc — пропустить» (видны, когда полосы встали; пробел — тоже «дальше»). Пропуск держится до конца сцены: реплики встают целиком и не держатся, голоса и Смерть молчат, камера суда не перелетает; вопрос с ответами пропуск не решает. Под полосами Esc — пропуск, меню паузы — на Esc без полос. Прогон: Esc на строке повтора — сцена ушла за 0,6 с. Ещё: в миг с убийцами вид сверху переезжает между поднятым и убийцами (раньше убийцы стояли у верхнего края); подпись весов над головой — на тёмной подложке; реплика над головой встаёт над весами, а не на них; строка повтора называет тот же голос, что весы над головой (весы писали «против: Похоть», строка — «решает Жадность»).

Записано: 66-DREAM-PLAN.md. Автор: ждём.
