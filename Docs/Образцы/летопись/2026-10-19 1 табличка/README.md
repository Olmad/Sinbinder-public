# 19 октября — Табличка — одна на все окна (46-UI §2.1)

Окна были двух семей — тёмная заливка с волосяной рамкой и плоская заливка без рамки, а подсказки висели голым текстом поверх мира. Теперь у всех одна табличка: край тёмного железа, линия старого золота, кожа, ромбики в углах; окна плотные — мир сквозь них не просвечивает. Подсказки (прогноз над приказами, строка «F — …») — на тонкой табличке по длине текста. Кнопки — следующий шаг (§2.2).

Записано: 46-UI.md §2.1 · 14-HANDOFF.md §111.18. Автор: ждём.
