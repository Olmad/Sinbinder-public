# 27 ноября — 27.11: карты экспедиций — земля с текстурой, настоящие ели, камни, шатёр с костром, груз на обозе

Автор 26.11: экспедиции «пустые и бесцветные» (серый пол, мало вещей). Ходят и сталкиваются по-прежнему с примитивами (навмеш по коллайдерам — раскладка та же), а видно вещи лагеря из Resources/MapProps: ели и мёртвые деревья, валуны, шатёр, факелы с огнём. Земля — хвоя бора (часовня) и старая дорога (обоз), тропа и дорога гравием, плиты развёрнуты по ходу — без ступенек. Края и стены часовни — камнем. Трава, кусты, пни и лес за краем карты — только вид, без коллайдеров. У шатра дозорных — костёр, на обозе — ящики и бочка. Зонд личной экспедиции: вошли, дошли, бой, отступили к знаку и вернулись — как раньше. Кадры сняты верстаком без тумана войны (ExpeditionLook).
