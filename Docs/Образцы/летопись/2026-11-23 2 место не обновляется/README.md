# 23 ноября — Место не обновляется — дозор Ордена в разграбленной часовне

Автор: «логично ли, что часовню разграбили, а она восстановилась через пару минут?» Теперь у мира есть время в походах. Вернулся сразу — та же ночь: раны у всех те же. Зачищенное место пустует. Разграбленную часовню через три похода занимает дозор Ордена (Брат Евсей, Брат Корнил), и журнал говорит почему: «Слух о разграбленной часовне дошёл до Ордена: у алтаря теперь их дозор».
