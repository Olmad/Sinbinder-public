# 22 октября — Греховод: ряса, юбка, пояс с пряжкой, посох; провал под капюшоном; без розового меча

Автор: «Греховод слишком нелепый», «тьму под капюшоном нужно сделать эффектами — сейчас это выглядит как будто это и есть его лицо». Облачение v2 (wear.py): тёмная ряса до земли, пояс с золотой пряжкой и гримуаром, посох вертикально с огоньком души. Розовый прут в левой руке был мечом ремесла «по умолчанию» из общих правил гардероба — Греховоду больше не выдаётся. Пустота под капюшоном — неосвещаемая чёрная (не ловит свет и не читается лицом) + тёмная дымка из глубины (HoodVoid).
