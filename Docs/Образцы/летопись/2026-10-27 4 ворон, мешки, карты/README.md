# 27 октября — Ворон и Гурт, мешки павших; карты «Перетягивания» и редактор

Лагерь: ворон сидит на плече Каргана и смотрит вперёд; Гурт ходит тенью за Хорем и целится туда, где брат будет через секунду; у Ждана в руках балалайка (пока без звука). Набег: у павших остаются мешки, кошель убитого берётся наклоном, вместе с душой. «Перетягивание каната»: в паузе есть страница «Карты „Перетягивания“». Это список карт из папки Maps рядом с игрой; по умолчанию там «Перекрёсток» на двоих и «Четыре склепа» на четверых. После выбора карты открывается лобби, где для каждого склепа выбирается игрок, ИИ (слабый, средний, сильный) или пусто. Кнопка «Начать» ведёт на поле, собранное из файла. Редактор карт: вид сверху, палитра вещей, склепов, подлокаций, троп охотников и событий; «Записать» кладёт карту в папку Maps. ИИ в лобби пока только записывается в выбор, он придёт шагом 3 (54-TUG.md). Кадров карт и редактора в прогоне нет: прогон их не снимает.

Записано: 54-TUG.md · 28-ORDERS.md — перетягивание каната. Автор: ждём.
