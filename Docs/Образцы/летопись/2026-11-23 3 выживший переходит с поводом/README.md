# 23 ноября — Охранник разграбленного обоза приходит с дозором Ордена

Первый переход выжившего между вылазками, по правилу «только живые и только с поводом». Обоз разграбили, а охранник Бажен Рыжий выжил: охранять ему больше нечего, он уходит на дорогу. Когда Орден посылает дозор в разграбленную часовню, Бажен приходит с ним, потому что знает Греховода в лицо. Журнал говорит это словами, а Бажен, узнав Греховода, говорит своё. Второе правило без кадра: бежавший живой через поход возвращается с подмогой, а покойник места не покидает.
