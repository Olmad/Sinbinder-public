# 17 ноября — Сон 16–17.11: из-за плеча в начале, убийца узнаёт по имени, миг с убийцами и суд — во дворе форта после уроков, причина повтора голосом

Задача автора 16.11: «собери великолепное обучение». Начало — из-за плеча Греховода: дорога со свечами, впереди форт и склеп; через 1,8 с камера поднимается над ним. Убийца узнаёт поднятого по имени (драма 01 ботов; из черновика реплик оставлена только эта строка). 17.11 автор: суд полный и «ближе к концу внимания — зацепить самым ясным, наглядным объяснением системы»; суд у ворот склепа над мигом, бывшим минуты назад, отвергнут («глупо не вовремя судить момент»). Теперь порядок: поднятие и первый приказ → поднятый идёт за Греховодом в форт → уроки глазами у чучела → в задних воротах форта встают убийцы → приказ, решение и сразу суд над этим мигом → бой режимом Воина, только что выученным → тот же приказ без убийц: не пошёл — строка называет решивший голос («теперь решает Жадность») → банка с камня в руку и к воротам (решение 12.11). Убийцы приходят, когда поднятый договорил свою первую фразу; общая подсказка «он пойдёт туда» во сне не показывается — там свои уроки. Хронометраж сна T0–T8 пишется в журнал, в dream-timeline.txt и в отчёт прогона. Кулак с посохом поднят над нижней панелью.
