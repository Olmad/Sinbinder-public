# 26 октября — Примета Марги Копателя — копает у края лагеря, лопата за спиной

Раз в минуту с небольшим Марга уходит к одной из трёх своих ямок на краю поляны и копает на коленях; через раз находит монеты — в карман и строкой в журнал. Оружие — лопата, в лагере она за спиной.
