# 21 октября — Лес вокруг лагеря: ели, сухие деревья, пни, кусты, трава

Автор: «сейчас это просто пустошь». В проекте не было ни одного дерева — сделаны в Blender (props.py): три сухих дерева, ель, пень, куст, сухая трава. Лес кольцом на 27–42 м, мелочь ближе; проходы свободны. Разведанное вокруг лагеря — до 42 м, лес виден серым. В открытии над палатками встали силуэты леса.

Записано: 14-HANDOFF.md §111.28. Автор: ждём.
