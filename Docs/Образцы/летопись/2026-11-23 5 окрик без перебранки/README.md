# 23 ноября — Окрик по имени больше не тонет в перебранке

На прошлом кадре окрик «Косой Ждан! Прохор Немытый лежит из-за тебя» шёл одновременно с обычным разговором отряда перед боем. Окрик звучит с 20 м, перебранка начинается с 15 м, так что при обычном подходе окрик первый, а теперь перебранка ещё и ждёт 8 секунд после него. Отряд в пробе стоит позади Греховода, как при настоящем подходе. Журнал: оба окрика по имени.
