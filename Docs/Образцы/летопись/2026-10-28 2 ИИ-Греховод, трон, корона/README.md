# 28 октября — «Перетягивание», шаг 3: Греховод-ИИ, осада трона, конец партии, корона на пустом троне

Греховод-ИИ (слабый, средний, сильный) встаёт в склепе своего места в лобби. Он собирает ничьих: идёт к очагу, дарит, зовёт за собой. Набрав верных, ведёт их на чужой склеп: сначала дверь, потом трон. Когда бьют его склеп, защищается. Правой кнопкой по чужому трону или двери — осада. Партию решает разрушенный трон. Павший Греховод не выбывает (автор, 28.10): кошель падает, где он пал, души и тела для жатвы нет, через минуту он встаёт у трона. Пока он лежит, на троне корона, а над ней полоса до восстания, которую видит только своя сторона.
