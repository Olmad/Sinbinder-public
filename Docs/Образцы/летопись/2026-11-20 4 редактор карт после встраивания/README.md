# 20 ноября — Редактор карт: встроены шаблоны WorldForge и проверка карты Codex

Две ветки редактора лежали в стороне. Ветка WorldForge даёт шаблоны композиций, выравнивание, выделение похожих и 3D-предпросмотр. Ветка Codex — проверку карты с переходом к ошибке, черновик после сбоя и 200 шагов отмены. Две параллельные проверки сведены в одну. Кадр — карта «Четыре склепа», открытая в редакторе после встраивания: подлокация, восемь шатров и костёр. Проверка на ней: «Ошибок формата карты нет». 302 проверки редактора проходят. Пакетный снимок, без панелей IMGUI.

Записано: MapEditor · MapValidator · MapEditHistory · MapDraftJournal · MapObjectTemplate. Автор: ждём.
