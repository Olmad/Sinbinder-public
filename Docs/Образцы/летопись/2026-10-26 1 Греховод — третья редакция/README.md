# 26 октября — Греховод — бывшая пешка Смерти в бегах; знамя глазами отряда

Ряса до середины икры с разрезом спереди, подол истрёпан, пыль и заплаты; плащ с рваным краем; гримуара нет; бронза — только кромка ворота и пряжка; посох костяной — позвонки по древку, огонёк в когтях. Шипы оплечья — как были. Второй кадр: после имени отряда Хальд говорит о знамени строкой над головой («все видят знамя по-разному»).
