# 19 ноября — Сон — карта обучения по рисунку автора (этап 1)

Сон теперь идёт по карте с рисунка автора: опушка с кругом камней (звезда) → умирающий → стоянка убийц с огнём и чучелом → развилка → мост с рычагом через реку → засада с валунами; лес серпантином в обход реки и озера; бревно через расщелину → площадь с колоннами и камнем с банками → прежняя дорога к форту, печатям и склепу. Края дорог — бурелом выше шага, по нему не ходят (проверено: из коридоров в чащу хода нет, река и расщелина закрыты, мост и бревно проходимы, путь опушка → ворота 237 м). Вода без отблеска неба. Пока сон идёт по-старому, только на новых местах: суд у стоянки, мост всегда опущен.
