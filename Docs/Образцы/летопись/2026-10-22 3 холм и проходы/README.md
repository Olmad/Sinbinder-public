# 22 октября — Холм — природный курган со спуском-языком; по верху предметов не ходят; коридор к выходу

Автор: «воины ходят по верхам палаток и других объектов — если до бедра, убирай»; «холму стоит придать более естественный, природный вид, то же самое со спуском». Всё выше 0,35 м в лагере — не навмеш: обходят, не залезают (кольцо у огня легло на брёвна, у карт — на бочки; точки теперь на земле). Холм — вылепленная сетка: ровная макушка, крутые бока с буграми, пологий спуск к костру. Две палатки с оси выхода убраны: путь наружу шёл по крыше брошенной.

Записано: 14-HANDOFF.md §111.33. коммит [`327f7f0`](https://github.com/Olmad/Sinbinder-public/commit/327f7f0). Автор: ждём.
