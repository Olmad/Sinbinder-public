# 23 ноября — Карта в шаре и кадр места в карточке экспедиции

Меню экспедиций в склепе открывается шаром: рельефная общая карта (холмы, река, леса, дороги, горы на северо-востоке) с точками мест, склепом и пепелищем лагеря; справа — что о месте говорят, кто ищет Греховода и «Продолжить игру». Та же земля теперь лежит в стекле шара на столе: огни отрядов стоят над местами, куда ушли отряды. Карточка места начинается с кадра этого места: шесть ночных сцен собраны из моделей игры (LocationShots) — пока первый проход, тёмные.
