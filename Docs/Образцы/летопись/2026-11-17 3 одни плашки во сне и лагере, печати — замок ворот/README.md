# 17 ноября — 17.11: сон и лагерь — одни плашки (задачи списком справа, клавиша на плашке урока); печати у ворот — замок; плиты-пустышки убраны

Автор 17.11: «по-прежнему есть плиты, которые просто есть»; «в лагере и в сне обучение и плашки с заданиями отличаются». Сон: шаг — задачей в списке «Задачи» справа сверху, прежний зачёркнут (как в лагере); клавиша шага — на плашке урока с клавишей в рамке; табличка «Воспоминание» вверху убрана. Лагерь: подсказки «как ходить», «как приказать», «вид сверху», «выдохся» — на той же плашке урока вместо своих панелей. Печати перед воротами — замок: Греховод на печать с венцом, поднятый по приказу на печать с мечом, знак разгорается; не встал — через 30 с ворота пускают одного (в прогоне он колебался — открылось одному). Сорок плит вразнобой, пластина на алтаре и светящееся дно чаши убраны.
