# 23 октября — Оберег — ворот цветом греха; у братьев нет куба над головой

У мёртвых воинов на плечах ворот с вышитыми ромбами — цвет его греха (Ждан — Гордыня, лиловый). Грех читается сверху внутри мира, а не кольцом интерфейса (суд облачной 22.10, 28-ORDERS §8.1). Бирюзовый куб над головами братьев (Хорь и Гурт) убран: их знак — лента на плече.
