# 6 ноября — Суд в обучении представляет воздерживающихся

Автор: «в обучении показать и представить недействующих судей». В первом суде Смерть объясняет, кто воздерживается, и каждый воздержавшийся встаёт в луче и называет свою причину: «Воздерживаюсь: ждать тут нечего». Подпись над ним — «воздерж.», в счёте — «воздержались». Короткий суд по делу этого не повторяет.
