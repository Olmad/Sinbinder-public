# 28 октября — Ничьи воины «Перетягивания», бревно у огня, учебник с гифками

«Перетягивание», шаг 2. Подлокации заселены ничьими воинами из генератора, в каждой партии новыми. Ничьи слушаются того, кто приказал, по верности к нему, а кого бить, решают сами. Верность растёт от поступков, и каждый грех ценит своё. Приказ по душе: гордому одному («Я поведу.»), гневному в бой, унылому недалеко. Ещё верность поднимают спасение и победа под твоим началом. Подарок: монета из кошеля партии, 20 в начале. Жадному он дороже всех, гордому почти ничего, а завистливый рядом обижается. В подсказке при наведении словом видно, как ничей к тебе относится. Лагерь: Греховод садится на бревно у огня. Учебник с гифками, снятыми прогоном: Docs/Учебник/учебник.html, копия лежит в D:/Claude/Учебник.
