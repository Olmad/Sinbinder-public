# 27 ноября — 27.11 вечер: отпущенный обоз уезжает — повозки катятся, цель снята, при повторном входе дорога пуста

Проход руками (Editor/ExpeditionHand: щелчки по земле, F — что игра предлагает, ответы кнопками), три прогона, три разные истории обоза. Починено по находкам утреннего прохода: старший нетронутого обоза стоит на дороге перед повозками (стоял за повозкой — был виден один силуэт); колёса в осях повёрнутого кузова; фонарь на передке; «Езжайте» — повозки катятся за охраной и скрываются, цель снята с мини-карты и с земли, F у пустого места больше нет, журнал: «Здесь больше нечего делать — вернитесь к бирюзовому знаку»; склеп — «Греховод вернулся из похода «Соляной обоз»»; повторный вход — ни повозок, ни охраны, ни цели, журнал: «обоз уехал, дорога пуста. Вернуться — у бирюзового знака». Осталось: охранник, отказавшийся уйти, всё ещё пишется в журнал «не выполнил приказ»; у истории со свадебным сундуком подсказка ответа «серебро ваше, если победите»; верстак: Греховод после щелчка проскакивает старшего (след обхода пролога — «Подойдите к алтарю» в журнале), второй щелчок доводит.
