# 19 октября — Первые минуты: пробуждение, выход, тёплый лагерь

Отзыв игрока 19.10: первый кадр — две плоскости ткани, ни точки, куда смотреть. Теперь Греховод просыпается лицом к выходу, на пологе дышит отсвет костра, внизу одна строка: «За пологом трещит костёр. Лагерь ждёт. W — идти · мышь — оглядеться». Пока идёт открытие, над воинами не висит «Колеблется…». В суме «пустая банка» ужимается, а не режется до «пустая». Холодный свет в лагере слабее (0,92 → 0,72), костёр шире (6,0 и 22 м).
