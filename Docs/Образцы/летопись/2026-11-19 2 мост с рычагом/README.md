# 19 ноября — Сон — мост: убийцы бегут, мост поднимают, приказ к рычагу; стрелка к месту

Убийцы узнают поднятого и бегут за реку; он гонится сам (или нет — решает душа). Тот, кто у рычага, поднимает мост у Греховода перед носом. Камера встаёт над обоими берегами, урок: выделить воина и ПКМ по рычагу — дальше решение и суд. Отказал — гонится к засаде, к ней — лесом; после боя тот же приказ. Рычаг тянет только тот, чья душа решила исполнить приказ. Стрелка к месту на каждом шаге сна; мост поднят — ведёт лесной тропой. Настил укорочен до 8,2 м (поднятый стоял стеной в 12 м).
