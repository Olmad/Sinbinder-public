# 7 ноября — Вызов Каргана виден; камера разговора не упирается в стену

Вызов Каргана (КТ1, п. 10) впервые снят изнутри мига: свет, полосы, удары в щит, крупный план с вороном. Раньше прогон снимал его после мига — общим планом сверху. Миг держится, пока строка допечатается, и ещё 1,2 с; слово «Колеблется…» над головой в кадре с полосами больше не висит. Разговор (п. 9): план выбирается так, чтобы кадр не закрывали вблизи стена, скат палатки или чужое тело; в тесноте — крупный план говорящего лицом к камере, а не полкадра палатки и не спина Марги. Остаток: камень без коллайдера у Марги ещё ложится на низ кадра.

Записано: 58-ROADMAP.md, КТ1 п. 9–10. коммит [`d2ed226`](https://github.com/Olmad/Sinbinder-public/commit/d2ed226). Автор: ждём.
