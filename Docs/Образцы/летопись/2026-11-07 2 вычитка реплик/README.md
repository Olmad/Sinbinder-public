# 7 ноября — Реплики демо вычитаны: точка на месте, суд и сон — к месту

КТ1, п. 12: весь сценарий демо прочитан по живому прогону — лагерь, набег, склеп и сон (прогон пишет каждую строку полосы в отчёт). Реплики глашатая — почти все у Каргана — обрывались без точки: по-русски она стоит за кавычкой и на полосу не попадала. Теперь на месте. Судья Терпение у гневной души говорил «Мне милее другое: драка» — теперь «Терпения в нём нет. Ждать он не умеет — бьёт первым». Подсказка сна — на «вы», как все. В журнале: название пластинки без двойных ёлочек («„Лунная соната“ составом „Крыс“»), напоминание «Карган ждёт у стола с шаром.» не повторяется подряд. На слово автору — в 47-TEXTS: «Сбегает» под наездом без имени.
