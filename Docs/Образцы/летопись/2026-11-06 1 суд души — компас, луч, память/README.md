# 6 ноября — Суд души: 13 судей, компас над весами, луч на говорящем, голос Памяти

Суд теперь доходит до вердикта в каждом прогоне: круг обучения ведёт каждый шаг сна. За кафедрой 13 судей; моральный компас (добро, середина, зло) висит над весами; подписи сторон не обрезаются. Воздержавшиеся проходят быстрым кругом, на говорящего падает видимый луч. Ошибка движка: память со знаком минус (гнев, страх, «меня убили») выпадала из выборки во всей игре. Теперь Память в суде говорит «Это они нас убили» (−80). Вопрос «как думаешь, послушается?» сделан и снят по слову автора.
