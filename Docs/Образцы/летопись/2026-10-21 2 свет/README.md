# 21 октября — Свет: свой лагерь разведан, тёплый остров, SMAA

Курс автора: графика — на первых местах. Свой лагерь разведан с начала, как база в Warcraft 3: окрестности в 30 м видны серыми, враги в них прячутся по-прежнему. Четыре факела между кольцами палаток — ткань освещена снаружи, лагерь читается тёплым пятном. Сглаживание по умолчанию — SMAA вместо мыльного FXAA.

Записано: 14-HANDOFF.md §111.27. коммит [`93b402d`](https://github.com/Olmad/Sinbinder-public/commit/93b402d). Автор: ждём.
