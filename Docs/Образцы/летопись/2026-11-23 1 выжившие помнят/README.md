# 23 ноября — Выжившие стражи помнят Греховода

У стражи личных вылазок теперь имена. Кто пережил встречу, записан в сохранение: где был, кого убил, бежал ли, сколько здоровья унёс. При следующем входе он там же: покойник привязан к месту, где его подняли, и кости у него не срастаются (19 из 30). Журнал при входе говорит, почему он здесь; узнав Греховода, он говорит, что было. Разговор перед боем больше не начинает Греховод и не ведёт воин из склепа: раньше на вылазке заговаривал Карган, оставшийся за 2500 м, и полосы забирали камеру.
