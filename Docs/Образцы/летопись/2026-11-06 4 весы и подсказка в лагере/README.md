# 6 ноября — Лагерь: весы над головой и строка весов в подсказке; подсказка читается

Язык суда проверен в лагере. Над воином, решившим по приказу, встают малые весы («за приказ: Верность»). В подсказке при наведении строка «Весы: за приказ — Верность, Смирение · против — Уныние, Совесть, Добродетель» идёт цветами голосов. Заодно нашлась старая беда: цвет греха красил весь фон подсказки, и на жёлтом Уныния текст не читался. Теперь фон тёмный, а грех показан рамкой. Плашки подсказок прилетают из центра один раз за сессию и не летят поверх урока или сцены с полосами.
