# 7 ноября — КТ1: кадры постоянного списка; журнал не лезет в кино, облачко — на девиз

Проверка КТ1. Прогон теперь сам снимает кадры постоянного списка: общий план лагеря ночью, костёр крупно с Жданом на бревне, разговор с выбором (Хорь, два ответа), дверь склепа с лучом и пылью. По кадрам исправлено: журнал возвращался, пока полосы кино ещё уезжали, — теперь ждёт, когда уйдут; облачко «Марга Копатель: „Ага…“» лежало на девизе «Не командуй. Искушай.» — пока стоит название, облачков нет; Хорь застревал, когда Гурт шёл ему «за спину» сквозь него — Гурт теперь отходит с дороги. Режет глаз (отчёт — D:/Claude/кадры/КТ1): плоская стена палатки за Карганом в «Вызове», пламя в расфокусе на кадре костра.
