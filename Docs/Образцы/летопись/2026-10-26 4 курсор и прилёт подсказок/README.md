# 26 октября — Свой курсор — скелетная рука со статусами; подсказки прилетают из центра

Курсоры слева направо: обычный палец; свой воин — банка с душой цветом его греха (Гордыня, Жадность); свой, но далеко — банка тусклая (приказ дойдёт тише); враг — клешня; вещь на F — ладонь; угасающая душа — пустая банка; ожидание в кат-сцене — душа прыгает в банке. Системный курсор на кадры прогона не попадает — это лист картинок, в игре смотреть руками. Подсказки (ходить, приказывать, жатва, силы) теперь появляются крупно в центре экрана и улетают на место (кадра нет — летят полторы секунды).
