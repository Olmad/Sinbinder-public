# Sinbinder: Grimoire of Vice

Тактика в реальном времени, где воины — души с грехами, моралью
и памятью. Они **голосуют внутри себя**, что делать. Приказ игрока —
один из голосов, а не команда: он участвует в голосовании как
`ActionType.ObeyCommand` и может проиграть.

> Не командуй. Искушай.

Полный замысел — в `docs/`. Начинать с `docs/README.md`;
`docs/03-STATUS.md` — что работает на самом деле,
`docs/11-MISSING.md` — чего не хватает.

---

## Что это за папка

```
Assets/          скрипты игры — то, что копируется в проект Unity
  AOS Engine/    движок личности: контекст, модули, голосование
  Core/          душа, память, отношения, кризисы, добродетель
  Gameplay/      воин, бой, приказы, умения, пол (усталость, зацепление, спина)
  UI/            надголовный интерфейс, подсказки, журнал, экран сборки
  Audio/  Dialogue/  Inventory/  Utilets/
  Tests/         самопроверка движка
Tools/           проверки: статический анализ и запуск Unity без редактора
docs/            замысел, аудит, планы
```

**Это ещё не полный проект Unity** — здесь есть `Assets`, но нет
`ProjectSettings`, `Packages`, сцен и ассетов. Содержимое `Assets`
копируется в настоящий проект; `Tools` и `docs` живут рядом с ним,
а не внутри.

Из-за этого здесь нельзя ни собрать, ни запустить. Проверять — двумя
способами ниже.

## Проверка без Unity

```
python3 Tools/check.py
```

Статический анализ: типы из чужих `namespace` без `using`,
несуществующие типы, дубликаты, литерал не того типа, использование
до объявления, LINQ без `System.Linq`, скобки, имя файла ≠ имя
MonoBehaviour, редакторный скрипт без `#if UNITY_EDITOR`.

**Запускать после каждой правки.** Этой проверкой в проекте найдено
23 ошибки компиляции, каждая из которых в одиночку не давала собрать
проект — то есть скрывала все остальные.

## Проверка с Unity

```
powershell -ExecutionPolicy Bypass -File Tools\unity-check.ps1
./Tools/unity-check.sh                                    # macOS, Linux
```

Запускает Unity в пакетном режиме, компилирует, прогоняет самопроверку
движка и печатает ошибки. Редактор открывать не нужно.

Самопроверка (`Tests/SelfCheck.cs`) проверяет логику: спектры, перенос
старых душ, распад, оболочки, искушения, геометрию удара в спину,
правила голосования и правило «игрок никогда не видит цифр».
Из редактора — меню **Sinbinder → Проверить движок**.

## Правила проекта

**Игрок не видит чисел.** Никогда. Ни очков, ни весов, ни процентов —
только слова. Четыре ступени прозрачности: значок → подсказка при
наведении → журнал → трассировка для разработчика. Первые три видит
игрок, четвёртую — нет. Это проверяется автоматически, см. `TextRules`
в `SelfCheck`.

**Ничего случайного.** Одинаковый вход обязан давать одинаковый выход.
Поведение рождается голосованием модулей, а не `Random.Range`. Одно и то
же решение всегда описывается одними и теми же словами — иначе игрок
не может учиться на объяснениях.

**Отношения вычисляются, а не хранятся.** Они складываются из общей
памяти. Отдельное поле связи создаёт вторую правду о персонаже, которая
рано или поздно разойдётся с первой.

**Добродетель — отрицательная половина шкалы греха.** Щедрость это
Жадность со знаком минус. Семь шкал, а не четырнадцать сущностей.

**Механика обязана проходить через личность.** Если её не читает ни
один модуль — это вторая игра сбоку. Если она бессмысленна без модулей —
это костыль. Нужно и то и другое.

**Мёртвый код хуже отсутствующего.** В проекте уже было ~900 строк
систем, которые никто не вызывает. Не добавляй класс, у которого нет
вызывающего.

## Правила Unity, о которые здесь уже спотыкались

- Имя файла обязано совпадать с именем `MonoBehaviour`, иначе скрипт
  нельзя повесить на объект. Пробелы в именах файлов недопустимы.
- `using UnityEditor` вне папки `Editor` — только внутри
  `#if UNITY_EDITOR`, и обёртка должна стоять **выше** `using`.
- ScriptableObject-базы грузятся из `Resources`. Если ассета нет,
  система обязана работать на значениях по умолчанию и сказать об этом
  один раз — см. `AOSConfig.Load()`. Молча возвращать ноль нельзя:
  отсутствие одного файла так выключало всю личность разом.
